# PROJECT_MAP.md
Project: TechCare Clinic. Backend `backend\TechCare.Clinic.Api` (http://localhost:5210). Frontend React RTL `frontend`. DB: Postgres+pgvector Docker `techcare-vector-db` port 5433. Tests in `backend\TechCare.Clinic.Api.Tests` (SQLite in-memory + fakes).

## Backend layout (TechCare.Clinic.Api)
- `Program.cs` — DI, JWT, CORS, Serilog, migrations on start.
- `Domain\Entities.cs` — all entities (User, Clinic, Patient, Visit, Appointment, Invoice, AiSettings, AuditLog...).
- `Data\` — DbContext, Migrations.
- `Infrastructure\` — audit, file upload helpers.
- `Features\Ai\` — medical library + AI:
  - `AiController.cs` — `api/ai/*` endpoints (search, assistant, alerts draft, settings...).
  - `ClinicalAssistantService.cs` — builds prompts, calls LLM, injects library evidence + patient constraints.
  - `LmStudioClient.cs` — LLM HTTP client, reads effective AiSettings.
  - `MedicalLibraryService.cs` / `VectorStore.cs` — pgvector search, source weighting, evidence tiers (task 2.x retrieval).
  - `QueryRouter.cs`, `LibrarySourceTypes.cs`, `PharmacyBrandMap.cs`, `ContentSignature.cs`, `DocumentTextExtractor.cs` — library support.
  - `LibraryController.cs` — owner-only library admin (upload/delete/reindex/list).
  - `AiSettingsService.cs` — AI settings from DB (global + per-clinic), task 1.2.
- `Features\Alerts\AlertService.cs` — draft-visit alert rules (task 3.1).
- `Features\Visits\VisitsController.cs` — `api/visits/*` incl. `drafts/alerts`.
- `Features\Patients\PatientsController.cs` — patients CRUD + code gen + data rights (9.3): `DELETE {id}` logical delete, `POST {id}/anonymize` one-way identity hide, `GET {id}/export` full-file payload. `PatientCodeGenerator.cs` (codes skip logically deleted rows), `PatientRetentionService.cs` (BackgroundService: purges files past `Clinic.DataRetentionDays`, every 6h + at startup; registered under its own type in `Program.cs`).
- `Features\Visits\VisitsController.cs` — also 5.1: `POST api/visits/{id}/attachments` (PNG/JPEG, signature-checked, random name, per-clinic `PatientFiles/{clinicId}/` folder from `Files:AttachmentsPath`), `GET api/visits/{visitId}/attachments`, `GET api/visits/attachments/{id}`; entity `VisitAttachment` (cascade from Visit).
- `Features\Queue\` — `QueueService.cs` (ordering `QueuePosition`: urgent → due on-time before late → future-slot by time; learned avg; estimates), `QueueController`, `AppointmentsController`, `QueueHub`, `ScheduleService`. `Features\Invoices\InvoicesController` (create auto-links appointment + back-fills visit, 409 on duplicate; `VisitsController` back-fills invoice VisitId when the visit is saved). `Features\Auth\`, `Users\`, `Owner\`, `Audit\`, `ClinicSettings\`, `Dashboard\`, `Public\` — feature areas.

## Frontend layout (frontend/src)
- `pages\PatientDetail.tsx` — patient file + visit form (examination form, diagnosis field, alert banners, prescriptions). Visit form lab/radiology field (10.10): `components\LabRequestsPicker.tsx` (searchable multi-select chips from `GET api/catalog/items`, free-text addition, saves plain newline-joined names).
- `pages\Patients.tsx`, `Queue.tsx`, `Appointments.tsx`, `Invoices.tsx`, `Dashboard.tsx`, `Library.tsx`, `Settings.tsx`, `Assistant.tsx`, `Login.tsx`, `Print.tsx`.
- `components\` — Layout, Modal, RichText, PatientForm, PatientPicker, FrontDesk, Icon, ErrorBoundary.
- API calls: plain `fetch` to `http://localhost:5210` inside pages (no separate service layer).
- `components\VoiceInput.tsx` — 5.2 mic dictation (Web Speech API, ar-EG, interim results, Arabic fallback note); used in PatientDetail visit fields + Assistant question.

- AI alerts during visit (3.1): `AlertService.cs` + `VisitsController` (`POST api/visits/drafts/alerts`) + banners in `PatientDetail.tsx`.
- Second opinion (3.2): `ClinicalAssistantService.DifferentialAsync` + `AiController` (`POST api/ai/differential`) + «رأي ثاني» button/modal in `PatientDetail.tsx` (SecondOpinionModal).
- AI assistant / search (2.x): `AiController.cs` + `ClinicalAssistantService.cs` + `Assistant.tsx`.
- AI settings (1.2): `AiSettingsService.cs` + owner panel in `Settings.tsx`.
- Visit images + PDF (5.1/10.11): `VisitAttachment` + `VisitsController` attachment endpoints + `ContentSignature` PNG/JPEG/PDF checks, 10 MB limit; UI: `AttachmentThumb`/upload button in `PatientDetail.tsx` VisitCard (image thumbnails; PDF shows a file icon; both open the protected endpoint via blob URL in a new tab). Mic dictation (5.2): `VoiceInput.tsx`.
- Queue team messages (6.1): `QueueMessage` entity + `AddQueueMessages` migration; `QueueService.TodayMessagesAsync/SendMessageAsync` + `GET/POST api/queue/messages` in `QueueController` (queue permission; foreign/other-day appointment link → 404/400 via `QueueException`/`QueueItemNotFoundException`); payload-free `messageSent` hub event through `QueueNotifier.MessagesChangedAsync`; UI: «رسائل الفريق» section in `pages/Queue.tsx` (thread + composer with today's patient picker + instant "new note" notice) wired via `useQueueSignal`'s `onMessage`; tests: `QueueMessageTests.cs` + 2 RoleMatrix rows.
- AI disclaimer + interaction log + budget (9.1/9.2/9.4): `AiInteraction` entity (`Domain\Entities.cs`) + `AiController.LogInteractionAsync`; `GET api/audit-logs/ai` (clinic admin, `AuditController`) and `GET api/owner/audit-logs/ai` (owner, `OwnerController`); log cards in `Settings.tsx` (clinic) and `owner/OwnerHome.tsx` (owner); interactive 60 s budget + one retry in `LmStudioClient.WithInteractiveBudgetAsync` (`AiOptions.InteractiveTimeoutSeconds`); tests in `AiInteractionTests.cs`.
- Subscription (10.2/10.3/10.4): `Infrastructure\SubscriptionGuard.cs` (30 s cache; read-only lock for Suspended/Expired/lapsed trial+active) applied by middleware in `Program.cs` (403 Arabic on non-GETs) + `AiPlanFilter` in `Features\Ai\AiController.cs` (Basic or `AiEnabled=false` → 403 Arabic on AI calls) + `SubscriptionInfo` (shared days-remaining math) + session fields `plan/subscriptionStatus/daysRemaining/aiEnabled` in `AuthController.ClinicView` (login/me) and `GET api/clinic`; UI: `SubscriptionBar` under the topbar in `components\Layout.tsx` (`.sub-bar` warn/danger in `index.css`); owner controls in `OwnerController` (`PUT /api/owner/clinics/{id}/subscription`, payments); tests in `SubscriptionTests.cs`.
- Auth/users (7.x): `Features\Auth`, `Features\Users`. **Usernames are unique across the whole installation** (not per clinic; the owner/super-admin account included): login checks the name system-wide (`IgnoreQueryFilters()`) → 409 only if two+ clinics still hold it, else 401. `POST /api/users` and `POST /api/owner/clinics` (admin username) both 409 «اسم المستخدم مسجل مسبقاً» when the name is taken anywhere. Migration `20261005180000_GlobalUniqueUsername` renames legacy duplicates (name, name-1, name-2…) and swaps the per-clinic unique index for the global `IX_Users_Username`.
- Patient data rights (9.3): `IsAnonymized`/`IsDeleted`/`DeletedAtUtc` on `Patient` + `DataRetentionDays` on `Clinic` (`Entities.cs`, migration `AddPatientDataRights`); global query filter in `ClinicDbContext.cs` hides deleted patients everywhere; owner patient counts exclude deleted (`OwnerController`); UI: `DataRights` card in `PatientDetail.tsx` (JSON download, printable PDF via `PrintPatientFile` at `/print/patient/:id` in `Print.tsx`, anonymise/delete with confirm modals) + retention field in `Settings.tsx`; tests: `PatientDataRightsTests.cs` + 2 RoleMatrix rows (export reads the shared matrix patient, anonymise uses a throwaway file).
- User logical delete (10.6): `IsDeleted`/`DeletedAtUtc` on `User` (migration `20261007090000_AddUserLogicalDelete`); global query filter in `ClinicDbContext.cs` (`ClinicId == CurrentClinicId && !IsDeleted`) hides deleted accounts everywhere; `AuthController.Login` excludes them explicitly (401); `OwnerController` staff lists/counts exclude them; `DELETE api/users/{id}` in `UsersController` (400 self/last-active-admin, renames username to `{name}-del-{id}` freeing the global name, TokenVersion++, audit "Deleted"); UI: «حذف» button + `DeleteUser` confirm modal in `Settings.tsx` UsersCard; tests: `UserLogicalDeleteTests.cs` + 1 RoleMatrix row.
- Catalogs (10.8/10.9/10.10): entities `DrugCatalog` and `CatalogItem` (Lab/Radiology, ClinicId 0 = shared owner list, tenant filter keeps clinic + shared) in `Entities.cs`; owner import/preview/save/search in `OwnerController` (`api/owner/catalog/*`), clinic admin PDF preview/save in `ClinicController` (`api/clinic/catalog/*`); **10.10 read endpoints for the visit form**: `Features\Catalog\CatalogController.cs` — `GET api/catalog/drugs?q=` (prefix-then-contains, 15) and `GET api/catalog/items?type=&q=` (clinic + shared, 50), policy `Assistant`.
- New clinic registration (10.1): `POST api/owner/clinics` in `OwnerController` (SuperAdmin; unique `Slug` → 409, slug charset check; admin `User` with `MustChangePassword=true` via `PasswordPolicy`; default fees 300/200, entity-default schedule; returns `NewClinicRequest` payload + admin credentials once) + «عيادة جديدة» button + `NewClinicModal` in `frontend/src/pages/owner/OwnerHome.tsx` + `POST api/owner/clinics` RoleMatrix row (fresh slug/username per call) + 4 tests in `OwnerPanelTests.cs`.
